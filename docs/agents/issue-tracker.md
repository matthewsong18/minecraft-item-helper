# Issue tracker: GitHub

Specs and tickets live in GitHub Issues for
matthewsong18/minecraft-item-helper. Use the gh CLI.

- Publish a spec or ticket by creating an issue.
- Read issues with their comments and labels.
- Write multiline bodies to a temporary file and pass --body-file.
- Use issue dependencies to record blockers. If unavailable, record
  "Blocked by: #<number>" in the issue body.
- Apply triage states using docs/agents/triage-labels.md.

PRs as a request surface: no.
